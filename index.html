HTML - язык гипертекстовой разметки

HTML (HyperText Markup Language) - это стандартный язык разметки документов, предназначенный для создания веб-страниц. Браузеры интерпретируют HTML-код и отображают его в виде интерактивных страниц с текстом, изображениями и ссылками.

Элементы HTML являются строительными блоками веб-страниц. Они обозначаются с помощью тегов, например, <p> для абзаца, <h1> для заголовка или <a> для гиперссылки. HTML позволяет встраивать изображения, создавать списки, таблицы и интерактивные формы.

Язык был разработан британским учёным Тимом Бернерсом-Ли в 1989-1991 годах. С тех пор HTML постоянно развивается. Современная версия - HTML Living Standard, которая поддерживается всеми основными браузерами. Вместе с CSS и JavaScript HTML составляет основу современного веба.
